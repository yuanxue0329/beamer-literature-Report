# LaTeX 文献汇报

将原论文的证据整理成连贯、精炼、图片清晰的 Beamer 汇报。核心排版偏好是：**在保留标题、校徽与页脚的前提下，让有效图片内容尽可能占据幻灯片主体区域，减少无用白边。** 当前用户要求和用户最新修改优先。

## 读取当前材料

- 先读取用户指定的最新 `.tex`、相关主题／样式文件和图片目录。检查页面比例、正文宽高、标题区、页脚区与现有字体，不默认 16:9，也不直接套用统一图片尺寸。
- 编辑前重新读取目标区域，保留用户已调整的分栏、裁切、偏移和合并页。不要从此前生成的正文片段或备份覆盖新版本。
- 若用户要求先看大纲，交付逐页标题、论点、图片与图注、实验数据来源和版式；用户授权实施后直接写入现有文件。
- 项目提供 AGENTS.md 或文献说明时，按其入口读取所需上下文；不假设存在特定个人目录或研究方向。

## 先看图片，再决定布局

对准备使用的图片执行下面的判断，尤其是流程图、拼接图和结果表。

1. **测量：**读取像素宽高、长宽比与已有 DPI。可运行 `scripts/inspect_images.py`；它也报告基于近白背景估计的有效内容边界。
2. **目视：**打开原图，识别主体、关键细节、子图分界、坐标轴、图例、图中文字、图注及白边。算法建议的边界必须经目视确认；非白色像素范围不等于可以安全裁切的范围。
3. **规划：**按裁切后的有效长宽比，选择单图、整页主体铺图、两栏、分解子图或续页。拼接图中的各部分可分别通过 TeX `trim`、`clip` 显示。
4. **放大：**先去掉无用边缘和重复图注，再放大有效内容。保留箭头、图例、标签、表头、单位与关键子图；不拉伸图片。密集表格无法读清时分开呈现。
5. **定位：**必要时利用普通正文边距中的可用空间，调整左右位置、列宽和列间距。偏移量由实际页面与内容决定，不固定使用 `-0.6cm`、`0.55\textwidth` 或 `1.1\linewidth`。

默认通过 TeX 调整显示，保留用户原始图片。像素尺寸决定分辨率与比例，不能在缺少物理尺寸依据时直接当成 `bp`。复杂裁切、缩放上限与越界判断见 [layout-recipes.md](references/layout-recipes.md)。

## 图片尺寸与页面边界

- 这里的“铺满”指主体区域，不覆盖标题、校徽、页脚，也不切掉科学内容。
- 同时指定 `width`、`height` 和 `keepaspectratio` 时，两者都是上限；只有当前起限制作用的上限改变，图片才会继续变大。
- 区分原图内部白边与幻灯片外侧正文边距。前者优先裁切，后者结合模板和主体区域调整；缩小图像通常会使白边更明显。
- 可根据当前用户的要求适度超出普通文本栏，但必须检查图像、相邻列、图注与页面物理边界。列宽合计大于 `\textwidth` 再叠加负偏移时，不能仅凭参数判断没有重叠或越界。
- 比较备选版式时，以图内小字和关键细节是否易读为准，不以“图片文件框够大”为准。
- 纵向拼接图重排的案例见 [layout-case.md](references/layout-case.md)；仅在需要参考这类双栏布局时读取。

## 文案、证据与叙述

- 每页围绕一个论点，优先用原论文图或表配简短图注与少量说明；文字忠实概括原文。按主题、机制与实验建立逻辑，减少不同综述间的重复。
- 使用用户提供的论文插图和截图；文献汇报默认不生成替代性插图，不为填满版面虚构结论。
- 以实际图表内容核对来源，不能只按文件名判断图号。复用拼接截图时检查表头、图注是否错配、缺失或重复。
- 实验数据保留任务、模型、场景、统计条件、分母、单位及消融定义。区分仿真与实机演示、模型推理与规划器求解、单次调用与端到端时延。
- 彩色批注可用来筛选用户重点，但不自行解释颜色含义。原文结论、用户评论与面向研究课题的迁移设想应当分清。

## 熟悉的 LaTeX 写法

- 沿用 `frame`、`frametitle`、`columns`、`figure`、`itemize`、`enumerate`、`block`、`tabular`、公式等简单结构；尽量不加宏包、复杂新命令或重做模板。
- 机制步骤使用 `enumerate`；阶段名可用 `\textbf{阶段：}`，后接一句核心内容。要点用 `itemize`，避免长段落。
- 内容确需分页时使用 `allowframebreaks` 配合显式 `\framebreak`，使图片、说明和引用留在对应页。连续主题页可合并，但不能因此把图表缩得难以阅读。
- 每张图配精炼的中文图注及原图表号。裁去重复英文图注时，应保留其有用信息并在中文图注中表达。
- **默认引用方式（可由用户指定）：**每篇论文仅在首次出现页用正文角标和页末脚注列题名、出版情况与 DOI，默认不列作者；后续页保留图表号和短图注。没有角落文献标识。项目另有明确规定时以最新要求为准。
- 源码使用合法 LaTeX，例如 `\hspace*{...}`、`\textbf{...}`、`Fig.~8--10`；不要把聊天中的 Markdown `**` 或转义的 `\hspace\*` 复制进 `.tex`。

## 交付与复用

- 实施前备份最新源文件，仅修改授权章节。保留项目编码和换行形式，避免无关格式化。
- 核对图片路径、图表身份、关键数值、引用位置和源码结构。**默认仅交付 TeX，不自行编译、不生成 PPT。**
- 已有编译 PDF 或用户截图可以用于查看效果。只有用户要求或已授权编译／视觉核验时，才生成新预览并据此迭代；不能将未编译的源码检查说成已确认最终排版。
- 简短报告文件位置、内容变化与尚未确认的渲染结果。将用户新确认的布局经验更新到对应参考，不把一次偏移或某一项目的论文顺序变成所有报告的固定规则。
