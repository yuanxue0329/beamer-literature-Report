# content-planning：文献汇报内容策划

用于把论文、阅读笔记与批注组织为有证据支持的汇报内容。它补充“讲什么、为什么选这些证据、按什么顺序讲”；图片尺寸、裁切、缩放、分栏、偏移、模板、引用位置和交付形式继续执行主技能及原有排版参考。

## 1. 何时调取

- 用户明确要求“调取 content-planning”“内容策划”“先拟汇报大纲”。
- 新报告需要确定研究问题、论文分工、主要论点、图表选择或讲述顺序。
- 需要把多篇论文或彩色批注融合为主题叙述，减少内容重复。
- 已有报告需要核正证据对应关系、实验解释或跨页术语。

只调整现有图片大小、裁切、位置、列宽或其他局部版式时，复用已有内容，不默认重新策划全篇。已有明确大纲时直接补充或修订所需部分，不要求再走完整流程。

## 2. 从实际汇报任务开始

优先从当前对话与项目材料中确定受众、汇报目的、论文范围、已有知识、用户批注和已确认顺序。只对会影响内容取舍且无法从材料确定的问题提问。

- 先看元数据、摘要、章节标题、主要图表与图注，找出问题、方法和关键结果。
- 再回查支撑所选页面的正文、实验、附录和必要公式。解释不清或证据有分歧时继续查原文，不根据图注猜细节。
- 用户已有截图时先核对截图内容与来源，避免重复提取全部图片；所需截图缺失时明确指出原图号。
- 标明实际阅读范围。只有摘要或片段时保留材料边界，不填入未查阅的实验与结论。
- 彩色高亮用于识别用户关注点；评论与原文分开记录，不擅自给颜色赋予固定语义。

## 3. 按论证方式组织，不固定页数

先识别论文的主要贡献类型，再按汇报需求选择相关环节。一个环节不必对应一页；用户确认的顺序与标题优先。

| 类型 | 适合的内容主线 | 应解释的重点 |
|---|---|---|
| 方法、算法、系统 | 具体瓶颈 → 方法整体 → 关键设计 → 实验设置 → 对照结果 → 消融或失败 → 适用条件 | 每个关键设计解决什么问题，结果如何支撑其作用 |
| 综述、观点 | 研究范围 → 分类依据 → 主题与代表工作 → 分歧或缺口 → 作者综合判断 | 分类为什么有用，哪些观点来自综述，哪些证据来自原始论文 |
| 数据集、环境、基准 | 需求 → 任务与数据设计 → 构建过程 → 评价方法 → 验证 → 获取与复用条件 | 覆盖了什么，如何验证质量，适合评估哪些能力 |

先用一小段内容梳理“研究问题、现有瓶颈、作者做法、关键证据和成立条件”。只在确有支撑时概括结论；不强制生成总结页、展望页或每页末尾的总结句。

多篇论文汇报先分配各文献的叙述作用，再展开单篇。对重复概念保留一次必要介绍，后续说明新增机制或不同证据；不要为保留文献数量而重复同一套背景。具体比较应有相同问题作为依据，不把不同任务与实验条件的数字直接排列成性能排名。

## 4. 逐页内容蓝图

拟大纲时，可用下面的紧凑字段帮助用户修改。内容蓝图不是额外的排版模板，也不要求将所有字段放上幻灯片。

| 字段 | 应交代什么 |
|---|---|
| 标题与本页目的 | 听众看完应理解什么；优先保留用户指定标题 |
| 核心内容 | 一个方法设计、实验发现、比较问题或必要背景 |
| 原文证据 | 对应图、表、子图、公式、章节或批注，并核对版本 |
| 必要解释 | 看懂证据所需的条件、指标、符号与少量说明 |
| 前后关系 | 为什么本页接在上一页之后，下一页还需回答什么 |

封面、论文首页和大图页可以只保留必要标题、图注与引用。正文要点数量服从内容与现有版面，不套用固定字数。公式先说明用途，再解释符号和输出含义；只有原文或明确标注的教学例子才能提供数值演算，不能把自拟例子当成论文实验。

标题可在原文支持且用户未指定时概括结果，也可使用简洁主题标题。没有独立信息的概括语句不另起页面。较长的口头解释仅在有帮助且符合交付要求时放入简短讲述提示或 TeX 注释，不默认生成整套讲稿或修改显示版式。

## 5. 选图与证据对应

为拟使用的素材说明它承担的作用：方法流程、主要效果、必要对照、组件贡献、稳健性、失败情况或实际部署。根据本页论点选择证据，不按原图顺序自动全收录。

对每张选图回答三个问题：

1. 图表实际展示了什么任务、对象、条件和结果？
2. 它能支持本页哪一项具体陈述？
3. 还需要哪些原文说明，才能避免误读？

图注描述展示对象、实验条件及必要图例信息；正文解释证据与论点的关系。不要逐项重复图中标签，也不要从图中没有报告的数据推导未经验证的优势。裁切范围和页面显示方法仍由现有排版规则决定；用户指定原表截图时继续使用截图，不强制重建图表。

### 来源的轻量记录

按需要在工作记录或 TeX 注释中保留：论文题名与版本、原图表号、子图范围、原文页码或章节、素材文件、拟用页面与用途。已有可靠记录时复用，不要求另外建立固定目录、JSON 或多个清单文件。

- 核对实际表体与图注，文件名不作为图号证据。
- 综述中的方法描述应追溯对应原始研究。参考文献编号只在所属文献内部有效。
- 区分预印本、会议版、期刊版；作者和年份相同不足以确认是同一篇论文。
- 来源不明时保留待核项，不凭记忆补 DOI、图号或页码。

这些内部记录不改变现有的首次引用与页末脚注规则，也不要求每页新增可见来源标签。

## 6. 术语、实验条件与指标

在第一次内容策划时，为反复出现的方法、模型、数据集、指标、缩写与符号保留简短对应记录。复用原文规范写法，必要缩写首次解释；已有项目术语优先。只有存在影响含义的冲突时才向用户确认，不为每次局部修改重复输出术语表。

引用定量结果时，核对实验场景、模型配置、基线、样本或试验次数、分母、单位、统计口径和必要消融定义。原文缺失则标“未报告”，不补入常见默认值。

对于机器人或算法文献，相关内容出现时尤其需要区分：

- 单机器人部署、不同构型展示与真正的多机器人联合决策。
- 仿真统计、实机定性演示与实机定量结果。
- 任务完成率、计划有效率与动作预测准确率。
- 模型推理时间、规划器求解时间、单次调用时间与端到端决策时延。
- 平均耗时、尾部或最坏耗时、模块更新频率与任务总完成时间。

这些区别用于确定措辞，不要求每页列出完整检查表。将单机器人结果推广到团队调度、或将某个模块的耗时推广到实时保证，应另标为待验证的研究设想。

## 7. 交付前的内容复核

根据已查到的原文与当前源码核对：

- 页面顺序是否帮助听众理解核心问题，有无明显重复或缺失的论证环节。
- 图表是否支持所写结论，是否夸大因果、泛化范围或作者的限定措辞。
- 数值、条件、版本、方法名与图表号是否前后一致。
- 是否清楚区分作者结论、用户评论、解释和待验证设想。
- 是否有未经核实的引文、无来源的数值、泛化空话或没有信息量的总结。

只修正相关内容，不以内容复核为由更换模板、字体、列宽、图片尺寸、裁切、偏移、脚注位置或现有分页。版面调整仍遵守用户授权和主技能规则。默认不编译、不生成 PPTX、不运行外部 PPTX 审计；没有查看新渲染结果时不声称已经确认最终排版。
